# 保存した時刻表記ガードの失敗

2026-10-21の最初のwhole-native比較実行。Nagoya run1のnative/Rust双方の終了コードは0、
観測台帳の照合も成功したが、全エポックの時刻対応付け検証で停止した。

`550380.19999999995343387`と`5.50380199999999953e+05`は同じf64を表す。
Decimalとして厳密比較したことが原因。[format-guard-failure.json](format-guard-failure.json)
に最初の差とf64表現を残した。失敗時のrunner、入力マニフェスト、両CSVとstderr、
終了コード、観測一致記録を保存している。全6走行が完了した証拠ではない。

ガードをf64ビット表現の比較へ修正し、ソルバー設定は変えずに
[新しいディレクトリ](../2026-10-21-native-rtk-common-inputs/README.md)で全6走行を実行した。
